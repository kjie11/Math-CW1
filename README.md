## **Description**

This repository contains the files and implementation for the first coursework assignment, which involves creating an **L-system tree generator**.  
This folder also includes the **generated tree images** and a **report**.


## **Hotkeys**

The application supports a set of keyboard shortcuts for loading configurations and adjusting L-system parameters in real time.

### **Configuration Loading**
- **1–9** — Load `configs/tree1.txt` to `configs/tree9.txt`  
- **A** — Load `configs/tree10.txt`

### **Parameter Controls**
- **↑ Up Arrow** — Increase angle by **+5°**  
- **↓ Down Arrow** — Decrease angle by **–5°**  
- **→ Right Arrow** — Increase number of **iterations**  
- **← Left Arrow** — Decrease number of **iterations** *(minimum 0)*  
- **W** — Increase **step length**  
- **S** — Decrease **step length** *(minimum 1)*

### **Random Mode**
- **R** — Toggle **Random Length Mode** *(ON/OFF)*
